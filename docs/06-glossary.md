# Glossary

| Term | Definition |
|------|------------|
| **Business Rule** | A declarative statement that defines or constrains business behavior; produces an outcome given inputs. |
| **BRD** | Business Requirements Document — describes business needs and rules without prescribing technical design. |
| **DTI** | Debt-to-Income ratio — monthly debt obligations divided by net monthly income. |
| **DMN** | Decision Model and Notation — OMG standard for decision tables and rule models. |
| **DPD** | Days Past Due — delinquency measure on a credit tradeline. |
| **Effective Date** | Calendar date from which a rule version applies to new evaluations. |
| **Hard Decline** | Automatic rejection with no manual path to approval without policy exception. |
| **LOS** | Loan Origination System — workflow for application capture and decisioning. |
| **REFER** | Outcome routing application to manual review queue. |
| **Reason Code** | Machine-readable code explaining decline or referral (e.g. `DTI_MAX`). |
| **Rule Version** | Immutable snapshot of a rule definition identified by version number. |
| **Shadow Mode** | Parallel evaluation logging outcomes without affecting customer-facing decision. |
| **Terminal Outcome** | DECLINE, APPROVE, or REFER — stops further rule evaluation. |
